# Mosaic brand assets

- `mark.png` and `kingfisher.jpg`: original image assets extracted from the user-provided Mosaic Private Office presentation (pages 2 and 1).
- `eb-garamond.ttf`: full variable EB Garamond font from google/fonts, distributed under the included SIL Open Font License (`OFL.txt`). Headings and wordmark use this font.
- Supporting type uses Aptos when installed, with Arial/Helvetica fallbacks; the wordmark caption uses Verdana, matching the cover.
- Core palette: navy #0e2b4c, deep navy #001d30, ink #132b3a, slate #627381, gold #c79d61, ivory #f4f1eb.
